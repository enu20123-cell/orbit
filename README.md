# ORBIT — персональный маршрут поступления

Рабочий браузерный прототип для кейса №2 LOCUS Startup Hackathon 2026. Целевая аудитория — ученики 10–11 классов из Центральной Азии, которые выбирают зарубежную программу бакалавриата.

## Что работает

- свободное описание цели: пользователь сам пишет страны, направление, бюджет, экзамены и год поступления;
- локальный демо-парсер показывает блок «Как ORBIT вас понял» и переносит распознанные данные в профиль;
- исходный запрос всегда отображается целиком; расширено распознавание стран и добавлен понятный fallback для неизвестной географии;
- прозрачная rule-based диагностика профиля;
- минимум три рекомендации с объяснением «почему подходит» и «что проверить»;
- прозрачная оценка совпадения 0–100 и категории ambitious / target / резервный без обещаний поступления;
- сохраняемый shortlist: выбранные программы остаются на устройстве и попадают в сравнение;
- сравнение двух вариантов;
- персональный roadmap и отметка прогресса;
- AI-поиск по всему интернету через Tavily с источниками, прозрачными критериями и персональным планом;
- каталог из 15 реальных программ с прямыми ссылками на официальные страницы как резервный режим;
- перерасчёт результатов при изменении текста цели или ключевых ответов;
- сохранение анкеты и прогресса в `localStorage`;
- адаптивная мобильная версия;
- WebMCP-инструмент `build_admission_route` для запуска основного сценария агентом.

## Данные и ограничения

Вузы настоящие, но требования, стоимость и выводы в этой версии — демонстрационные ориентиры, а не гарантия поступления. Перед подачей пользователь должен открыть официальный источник на карточке вуза. Дедлайны намеренно не выдумываются.

Основной подбор вызывает защищённый серверный endpoint `/api/plan`. Он использует Tavily Search с LLM-ответом, возвращает реальные веб-источники и не раскрывает `TAVILY_API_KEY` браузеру. При отсутствии ключа, лимите или сетевой ошибке сайт автоматически оставляет пользователю объяснимый локальный резервный подбор. Секретные ключи нельзя размещать в клиентском коде или GitHub.

## Запуск

Откройте `dist/index.html` в браузере или запустите любой статический сервер из папки проекта.

## Тестовый сценарий

1. Напишите: «Хочу поступить на Computer Science в Нидерланды или Германию. Бюджет до $24 000, IELTS 6.5, SAT 1280, поступление в 2027 году».
2. Постройте маршрут, добавьте два варианта в shortlist и проверьте, что сравнение переключилось на выбранные программы.
3. Замените текст на один из готовых примеров или измените бюджет — оценки совпадения, категории и roadmap обновятся.

## Использованные компоненты

Шаблон не использует внешний UI-kit. Интерфейс, стили, логика подбора и набор демонстрационных данных созданы специально для прототипа.
